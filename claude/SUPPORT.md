# Burn15 support

Website: https://burn15.com/

Contact oxygenDrop at danielbarassistant@gmail.com. Send an approximate time, operation, and redacted error description. Do not post secret note text or a complete note link in a public issue.

This plugin needs browser tools supplied by the assistant host for automated actions. Without them, it provides manual website steps. Notes expire 15 minutes after creation. This free experimental service has no promised uptime or support response time.

See [privacy and retention](PRIVACY.md) for the limits of burning and expiry.
